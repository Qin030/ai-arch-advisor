# 知識庫：這個目錄不准生成內容

## 最重要的一條

**你不得撰寫任何法規條文、統計數字或氣候數據。**

你在這個目錄只能做三件事：

1. 把**人工提供的原文**切成符合格式的切片
2. 填寫 metadata 欄位
3. 檢查格式是否合規

找不到原文、或 metadata 缺欄位 → 寫 `TODO: 待人工查證`，並在回報中列出清單交給人。

### 這種輸出是嚴重錯誤

> 「根據建築技術規則第 XX 條，住宅區建蔽率上限為 60%……」

如果這句話不是從人工提供的原文逐字複製過來的，它就是捏造。條號可能不存在，數字可能是別的縣市的，版本可能是十年前的。

整份企畫書的立論是「可查核」——每一筆資料都能追溯到來源、版本與適用地區。一筆捏造的切片，就足以讓評審在 Q&A 拆掉整個作品。**發現此類問題時停止所有作業並回報。**

## 切片格式

每筆 YAML 必填欄位：

```yaml
id: reg-tainan-001
type: regulation          # regulation | cost | climate
title: 建築技術規則建築設計施工編 第 X 條
source_org: 法務部全國法規資料庫
source_url: https://...
version_date: 2026-03-15  # ISO 8601，見下方〈version_date 的定義〉
region: tainan            # MVP 階段只有 tainan
license: 政府公開資料
content: |
  （原文逐字，不改寫、不摘要、不潤飾）
```

選填欄位：

```yaml
scope_condition: 防火構造建築物；排除基地鄰接寬度六公尺以上道路或深度六公尺以上永久性空地側
content_type: text        # text | figure，預設 text
```

`scripts/validate_kb.py` 在 CI 檢查上述欄位，缺一即紅燈。這是刻意的——讓「可查核性」由機器強制，而不是靠人記得。

### `scope_condition`：這筆條文的適用前提

有些條文的數值只在特定前提下成立（構造別、鄰接條件、基地規模…）。這種
條文**必填** `scope_condition`，把前提逐字（或緊貼原文）寫清楚；沒有適用
前提的條文可以省略這個欄位。

漏填的後果：模型會把有前提的數值當成無條件成立，等於系統自己做了「這個
基地符合前提」的推定——這正是規則層明文禁止的事。

### `version_date` 的定義：不是頁首日期

**`version_date` 是本切片所收條文文字的最後修正／制定日，從該條的沿革頁
取得，不是整部法規頁首標示的最新修正日。**

⚠️ 法規資料庫的頁首日期通常只反映「這次修正動到的少數條文」，不代表全部
條文都是那個日期——同一部法規裡，不同條文的實際最後修正／制定日可能
差很多年。**這裡刻意不放具體條號或日期當範例**：任何實例都必須是人工
親自開啟沿革頁核對過的結果，agent（不管有沒有用 WebFetch 之類的工具
交叉比對）不能替代這個核對，即使誠實揭露查證程度也一樣不合規——這正是
規則層鐵律第 3 條「找不到原文時寫 `TODO: 待人工查證`，不要填看起來合理
的內容」在講的事。

蒐集原文時，逐條點進沿革頁核對，不要只看頁首；核對到的具體條號與日期
記進 `data/kb/VERIFIED.md`，不要寫在這份說明文件裡當範例。



### `content_type`：條文文字與圖例分開記

補充圖例（例如退縮距離示意圖）與條文文字的修正日期可能不同。兩者**各自
切一筆**，`content_type` 分別標 `figure` 與 `text`（省略時預設
`text`）。不得用圖例的修正日期覆蓋條文文字的 `version_date`，反之亦然。

## 切塊原則

- **法規**：以條、項、款為單位切，不用固定字數。固定字數會把「第一項」和「第二項」切開，語意就斷了。
- **成本**：依指標、時間、地區切。
- **氣候**：依測站、指標、統計期間切。
- **交叉引用**：遇到「依前條規定」「準用第○條」，在 metadata 加 `refs: [reg-xxx-002]`，檢索時要能一起取回。

## MVP 配額

法規 10 筆 / 成本 8 筆 / 氣候 7 筆 = **25 筆**。

不要多產。25 筆是刻意的上限——每一筆都要人工查證來源，D4 的預算就是這麼多。產 60 筆等於沒有一筆被查證過。

## 資料來源（只用這幾個）

- 法規：全國法規資料庫、內政部國土管理署公開資訊、臺南市建築管理自治法規
- 成本：行政院主計總處營造工程物價指數、政府工程公開價格
- 氣候：交通部中央氣象署開放資料平臺

不在這份清單上的來源 → 先問人。不要爬網站，不要用二手整理的部落格文章。
