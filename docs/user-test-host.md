## 開場照讀與順序

> 今天測的是系統是否容易使用，不是在考你的建築知識。請使用我們提供的
> 虛構情境，不必提供自己的地址或家庭資料。你可以隨時跳過問題或停止。
> 請照自己的理解操作；若卡住可以告訴我。畫面內容是需求整理材料，涉及
> 法規、設計或工程的判定，仍需由專業人員確認。你的回饋不必正面。

背景題 → 前測四題（收回）→ 任務卡與操作 → 後測四題 → 採用意願 → 訪談。
前測前不展示 UI，後測前不公布答案。協助先詢問並記提示原話，不能提示後仍記獨立完成。
