## 驗收方式

M2 在 D10 拿這張表逐列對照企畫書實際文字。每列要能指到：

- 改過的段落，或
- 一個能支撐原文的實作／實測數據

兩者都給不出來 → request changes。

**僵持時採保守版本。** 少宣稱一項不會扣多少分；被評審在 Q&A 抓到宣稱與實作不符，
整個「可查核、可拒答」的立論就毀了——那是這件作品唯一的差異化。
