## C. 情境與任務卡（前測收回後才發）

主持備註：發放前只保留本輪事前納入的任務，保留 T 編號；用紙本或獨立螢幕呈現。

虛構情境：你希望在臺南自地自建二層透天，家中預計三人同住，希望家裡溫馨、動線方便，也想用手機控制智慧設備。你目前不知道基地地號與使用分區，預算也還沒確認。其他偏好可自行選擇；不知道的項目可以留白或跳過。

- T1：用自己的話開始規劃，完成畫面上的需求盤點。請不要為了填完而編造基地資料。
- T2：查看盤點後的輸出，找出已記錄的需求及仍需確認的事項；指出其中一項要問誰。
- T3：查看方案比較，說出一個差異與一項在選擇前仍要確認的資訊。
- T4：找到某項資料的來源資訊，說明你能在哪裡看到發布機關、版本、適用地區與連結。
- T5：若本輪包含編修匯出，刪除一項不想保留的摘要內容，標記一項重點並下載 Markdown 或 PDF，開啟下載檔確認內容。只需操作本輪實際提供的匯出格式。
